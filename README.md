# Combien facturer ?

Calculateur de prix pour un site web : il estime les jours de travail à partir du projet (type de site, pages, design, fonctionnalités) et du TJM, puis donne un devis détaillé.

C'est une application web installable (PWA) sur PC et téléphone, utilisable hors connexion.

- Le site est dans le dossier `docs/`, publié avec GitHub Pages.
- Pour tester en local : `node serve.js` puis ouvrir http://localhost:5173
